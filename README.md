# Titanic: Exploratory Data Analysis with pandas

Учебный проект по основам анализа данных на Python. Я отрабатываю на
датасете Titanic базовые операции pandas: от первого знакомства с данными
до фильтрации по нескольким условиям.

## Что сделано
- **Знакомство с данными:** размер таблицы (`shape`), список столбцов,
  `head()`, `describe()`, `nunique()`
- **Описательная статистика:** среднее, медиана, стандартное отклонение
  для возраста, стоимости билета и числа родственников на борту
- **Выбор и сортировка:** `loc`, `iloc`, `sort_values`, `nlargest`
  (например, топ-5 самых дорогих билетов, самые молодые пассажиры)
- **Пропущенные значения:** количество и доля пропусков по каждому столбцу
- **Частоты и доли:** `value_counts` по классу каюты, полу, порту посадки,
  доля выживших
- **Фильтрация по условиям:** например, выживаемость женщин первого класса,
  дети до 12 лет во 2-м и 3-м классах, пассажиры старше 60 из портов C и Q

## Инструменты
Python, pandas, Google Colab / Jupyter Notebook

## Данные
Открытый датасет Titanic (учебная копия из pandas-tutorial).

## Планы
Очистка данных, группировки (`groupby`), визуализация и NumPy.
